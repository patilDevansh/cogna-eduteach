# MVP 4.0 — Personalization

> **Delta from MVP 3.0:** Personalization becomes **unit- and horizon-aware** while keeping abstention and label-free copy.

## Principles

- Horizon plan suggests focus; evidence still gates remediation
- Bridge reviews prioritized when prior-unit retention weak
- Experiments remain sticky; may be nested per unit carefully (prefer one active experiment)

## Must not

- Jump units because of a single wrong answer
- Infer “learning disability” from slow unit progress
- Override parent workload caps for curriculum ambition

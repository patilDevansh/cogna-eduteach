# MVP 4.0 — Pilot Plan

> Prove multi-unit depth without multi-modal/learned-policy scope creep.

## Prerequisites

- MVP 3.0 exit criteria met (draft quality + experiment learnings)
- Spec freeze to Canonical
- Second unit bank ≥ pilot floor APPROVED

**Multi-unit cohort dependency:** MVP 4.0 pilot depends on successful MVP 3.0 pilot exit. The cohort for MVP 4.0 may include new students or continuing students from MVP 3.0 who have demonstrated readiness for multi-unit progression. Selection criteria and cohort size to be determined based on MVP 3.0 outcomes.

## Goals

1. Students unlock / practice a second unit with bridge reviews
2. Horizon plans stable for 4 weeks
3. Parent reports unit-aware and understandable
4. U## goldens green; G/R/S regression green
5. **Multi-unit readiness:** Validate that ≥70% unlock threshold correctly gates progression; no premature unit unlocks

## Out of pilot

- Full subject catalog
- Video/voice teaching
- Default RL policy

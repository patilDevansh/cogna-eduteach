# MVP 5.0 — Pilot Plan

> Research-grade, safety-first pilots — not a big-bang rewrite.

## Prerequisites

- MVP 4.0 multi-unit stable
- Large enough logged dataset for offline policy eval
- Modality review staffing

## Staged pilots

1. **Modality text+animation** on one math unit (rules policy only)
2. **Shadow learned policy** (no student effect)
3. **Experiment** learned vs baseline
4. **Optional** second subject thin slice

## Exit criteria

- Safety suite green; rollback drilled
- Modality math incident rate = 0 in pilot
- Parent comprehension of multi-modal reports acceptable
- Decision on default policy documented

## Out of pilot

- Unconstrained multi-agent tool use
- Clinical claims
- Live unchecked generative tutoring

## Question Checklist

For each question:

- [ ] ID is stable and unique
- [ ] version is correct
- [ ] concept ID is correct
- [ ] difficulty 1-5 matches rubric
- [ ] stem is unambiguous
- [ ] accepted answers are complete
- [ ] solution steps are correct
- [ ] hint ladder is helpful and not revealing too early
- [ ] misconception patterns match realistic wrong answers
- [ ] no unsafe or discouraging language
- [ ] review status set to `APPROVED`

## Explanation Checklist

- [ ] explanation matches concept
- [ ] explanation matches misconception
- [ ] check-for-understanding exists
- [ ] retest mapping exists
- [ ] parent-safe summary language exists

## Pilot Freeze

- [ ] manifest approved count >= 200
- [ ] no `PENDING_REVIEW` in pilot seed
- [ ] random sample manually rechecked after seed
- [ ] golden content validation green
